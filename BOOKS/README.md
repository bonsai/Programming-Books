# NEWBOOK

新しい本の制作プロジェクト。

> 原則: `BOOKS/` は既存の書籍資産のみ。新規書籍は `content/` で制作する。

## Structure

- `README.md` — book project definition
- `outline.md` — table of contents
- `research/` — source research
- `draft/` — manuscript drafts
- `review/` — review notes

## Production Flow

`SOURCE → TOC → CONCEPT → EMBEDDING → BQML → KNOWLEDGE GRAPH → OUTLINE → DRAFT → REVIEW → PUBLISH`
